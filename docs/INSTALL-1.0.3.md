## 从旧版迁移

1. 在旧版中进入“我的 → 备份与恢复 → 保存备份到本地”，把 ZIP 保存到下载目录或自己选择的网盘等应用外位置，并确认文件确实存在。不要只保留在会随卸载删除的应用目录里。
2. 确认备份已保存后，再手动卸载旧版，然后安装 renovation-ledger-1.0.3-signed.apk。卸载会清除旧版本地数据；没有备份时不要卸载。
3. 打开新版，进入“我的 → 备份与恢复 → 从备份恢复”，选择刚导出的 ZIP，恢复完成后按提示重启并检查账单和凭证。
